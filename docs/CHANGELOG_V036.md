# Dirt Money v0.3.6 Changelog

## Soil Test / Planting Calendar / Preparedness

- Replaced vague soil-test paragraphs with structured decision cards.
- Soil tests now record fertility rating, soil health, rotation concern, fertilizer ROI, best crop fit, this-year recommendation, next-season note, and background interpretation.
- Soil Test All now returns a readable per-field summary instead of one long paragraph.
- Removed duplicate top notice text for rich soil-test result cards.
- Added crop planting windows for corn, soybeans, hay, cover crop, and winter wheat.
- Newly leased Hollis Back 20 now obeys the same planting calendar as starting fields.
- Late corn, soybeans, and hay can carry explicit reduced-yield penalties when allowed.
- Added limited preparedness banking for IT Nephew and planning upgrades without enabling full work-slot rollover.

## Tests

- Added structured soil-test, soil-test-all, UI result, save/load, crop-window, leased-field, late-yield, and preparedness tests.
- Source suite now covers 103 tests.

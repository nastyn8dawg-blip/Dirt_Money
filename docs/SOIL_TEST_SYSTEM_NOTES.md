# Soil Test System Notes

## Purpose

Soil tests are decision support. They do not improve a field directly; they reveal what the player should do with cash, crops, fertilizer, rotation, and next-season planning.

## Structured Result

Each soil test records:

- Fertility rating: Poor, Low, Medium, Good, or Excellent.
- Soil health: Thin, Tired, Stable, or Strong.
- Rotation concern: Unknown, Good, Risky, or Repeated Crop.
- Fertilizer ROI.
- Best crop fit.
- This-year recommendation.
- Next-season recommendation.
- Plain-language reason.
- Background-specific interpretation.

## Background Reads

- Old School Farmer gets a practical field-sense interpretation.
- IT Nephew gets ROI/data-style interpretation.
- Mechanic gets a risk-prevention interpretation.

## UI Behavior

Single-field soil tests appear as a structured result card. Soil Test All appears as a compact summary list so the player can compare fields without reading one giant paragraph.
